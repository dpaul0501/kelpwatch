Data and quality

Knowledge base

Public kelp and eelgrass documents from Washington DNR, WDFW, the Northwest Straits Commission and partners: extracted, redacted, chunked and indexed. Search it the same way the agent does.

Policy and skills

Rules are written in plain language and compiled into checks that run in code, before and after the model. The model never decides whether a rule passed.
